# إقفال صناديق الكاشير — نسخة تجريبية

تطبيق جوال لإقفال صناديق الكاشير اليومية ومطابقتها مع تقارير نقاط البيع والشبكات، ومتابعة العجز والزيادة والتقارير.

## التثبيت على الجوال
- **آيفون:** افتح الرابط من Safari، ثم زر المشاركة ← «إضافة إلى الشاشة الرئيسية».
- **أندرويد:** افتح الرابط من Chrome، ثم ⋮ ← «تثبيت التطبيق».
